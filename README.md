# Lead Generation Agency OS

Operating blueprint for a retainer + commission lead-generation agency.

Stack named in this repo: HubSpot, Twilio, Claude, Lemon Squeezy.

This is not the live PipelineEdge floor. Do not copy retainer amounts, commission rates, or client commercials into call scripts. Live desk rules stay on https://os.pipelineedge.in.

## Operating map

Lead capture → qualification → discovery call booked → proposal sent → negotiation → closed won → retainer active → renewal check → monthly reporting → upsell opportunity.
